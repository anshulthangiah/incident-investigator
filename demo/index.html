Builder mode: what is real and what is replay only

Real: the command-line tool and its mock system run for real on your machine (python3 investigate.py --demo). The recordings on this page are real output of that tool, captured by scripts/record_demo.py.

Replay only: this page. It cannot run the tool, take a new question or call anything. It plays back what was recorded.

Next shows the next step. Play runs the steps one after another. Reset goes back to the start. Builder mode does not change them; it only adds the numbered markers. Tap a marker to read its card, then press the button on the card (Scroll to it, or Show me where this is) to move the replay to the step where that feature appears. It loads only what is missing and never takes away steps already shown.
